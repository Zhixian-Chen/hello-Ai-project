# 陈智贤 · 个人作品集

原生 HTML、CSS、JavaScript；零运行时依赖，无需安装或构建。暖白与深墨绿、大字号排版、真实作品主视觉，面向设计研究与空间设计的作品展示。

## 本地运行

```sh
python3 -m http.server 3000 --bind 0.0.0.0 --directory /workspace/hello-Ai-project
```

通过 HTTP 运行，修改后刷新浏览器。项目数据由 `fetch` 加载，不要直接双击 HTML 使用 `file://` 打开。

## 网站内容与交互

- 首屏有五组真实作品背景、轻微鼠标视差与对应项目入口。
- 七组作品支持方向筛选、画廊/目录视图，包含空间设计、设计研究、AI 探索、手绘与视觉。
- 每个项目有设计问题、思考方法、能力标签、三段过程与完整页序图集。
- 大图阅览支持缩略图、页码滑杆、左右键、Home/End、手机水平滑动、放大、可选系统全屏；Escape 先关闭大图，再关闭项目。
- 项目有可分享的片段链接，例如 `#project/tea`、`#project/children`；支持浏览器前进/后退及下一项目。
- 四步设计过程可展开，联动真实分析图，并链接对应项目。
- 包含覆盖式菜单、滚动显现、磁吸按钮、桌面光标反馈和北京时间。减少动态效果的系统偏好会关闭装饰性动画。
- 首页导航、关于区、菜单和联系区均有真实简历 PDF 入口。邮箱使用 `mailto:chen1902157635@gmail.com`，由访客的邮件应用处理。
- 微信入口点击即尝试复制 `18831181378` 并展示联系弹层。剪贴板不可用时，保留可选中号码及手动复制提示；不使用无法保证有效的微信深链或虚构二维码。

## 素材与内容来源

本次使用用户上传的 `1–41`、`42–52`、`53–65` 三份作品集 PDF，更新第 7–65 页与第 5 页的真实简历，并从简历原图提取肖像。第 66–79 页沿用仓库中已有作品素材，因此七个项目合计完整展示第 7–79 页，共 73 页。

完整作品页约 2569px 宽，以无损 WebP 保存；`assets/previews` 为详情页的轻量预览，`assets/thumbs` 为阅览器缩略图。大图始终使用完整页面，不裁去版面。首页与封面使用已有作品中的真实效果图，没有生成式补绘。页面输出分辨率不能恢复原始位图本来没有的细节。

内容由作品集整理；儿童空间项目为设计探索，不将方案表述为已验证的临床疗效，AI 历史场景不作为史实复原结论。教育与联系方式来自用户提供的资料。

## 修改内容

- `assets/projects.json`：项目标题、类别、说明、研究问题、能力、过程节点与完整页序。
- `index.html`：首页结构、介绍、教育、邮箱与微信入口。
- `script.js`：筛选、导航、图集、复制、动态效果。
- `style.css`：视觉、响应式布局与减少动态效果支持。

参考网站为 [Grid9](https://www.grid9.ru/?ref=minimal.gallery)。已读取其页面结构与交互脚本，将大字排版、沉浸式作品、覆盖菜单、分段过程和联系弹层等逻辑转为个人作品集语境。其部分外部 CDN 在当前环境仍受访问限制，未据此宣称逐像素复刻全部外部资源。本站运行完全使用本地素材，不依赖参考站、字体 CDN 或第三方服务。

## 验证

通过 Python Playwright 与系统 Chromium 进行实际浏览器检查，包括五类筛选、双视图、五组首屏切换、全部七组详情和完整页数、大图与键盘控制、滑杆、缩略图、放大、嵌套关闭、深链、浏览器历史、下一项目、过程展开、菜单、微信真实剪贴板内容，以及 320/390/768/1440px 布局。移动端另用 TouchEvent 验证横向滑动。对全部 73 页与 146 张预览/缩略图检查文件完整性和 HTTP 响应，并检查简历 PDF 响应。

`node --check script.js` 可用于 JavaScript 语法检查。功能测试需在 HTTP 服务运行时进行；浏览器中可验证筛选数量为：全部 7、空间 3、研究 1、AI 2、视觉 1。
